Tracked Stocks Configuration

The stocks displayed on this website are loaded from the static file stocks_list.json. You can add or modify stocks in this file anytime.

How to update stock data & deploy to GitHub Pages:
  1. Edit stocks_list.json to add your desired stocks.
  2. Run python3 scripts/extract_data.py to fetch full latest fundamentals.
  3. Push to GitHub! The GitHub Actions workflow will automatically deploy to GitHub Pages.
